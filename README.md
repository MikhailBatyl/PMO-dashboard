# PMO Dashboard — Портфель проектов и продуктов

Интерактивная веб-панель для управления портфелем проектов и продуктов проектного офиса.

- **Данные**: Google Таблица → Google Apps Script (API)
- **Фронтенд**: HTML + CSS + vanilla JS, хостинг — GitHub Pages
- **Редактирование**: статус, тренд, риск, причина отклонения — прямо из браузера

---

## Шаг 1 — Настройка Google Apps Script

### 1.1. Откройте редактор скриптов
1. Откройте вашу Google Таблицу (лист должен называться **«Статус проектов и продуктов»**).
2. Меню → **Расширения → Apps Script**.

### 1.2. Скопируйте код
1. В редакторе откройте файл `Code.gs` (или создайте его, если его нет).
2. Скопируйте содержимое файла `apps-script/Code.gs` из этого репозитория и вставьте в редактор.
3. Нажмите **Сохранить (Ctrl+S)**.

### 1.3. Разверните как Web App
1. Нажмите **Deploy → New deployment**.
2. Тип: **Web app**.
3. **Execute as**: Me (владелец таблицы).
4. **Who has access**: Only users in `<ваш домен Google Workspace>` *(не выбирайте «Anyone», чтобы данные не были публичными)*.
5. Нажмите **Deploy**. Google попросит авторизацию — разрешите.
6. Скопируйте **URL веб-приложения** вида:
   ```
   https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXXXXXX/exec
   ```
   Это ваш API-эндпоинт.

> **Важно**: при каждом изменении `Code.gs` нужно создавать **новую версию деплоя**:  
> Deploy → Manage deployments → Edit → Version: **New version** → Deploy.  
> Иначе изменения не применятся к выданному URL.

### 1.4. Проверьте API
Откройте URL веб-приложения в браузере — должен вернуться JSON с данными листа:
```json
{ "items": [...] }
```

## Шаг 2 — Вставьте URL в фронтенд

Откройте файл **`api.js`** и замените строку:
```js
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/ВСТАВЬТЕ_ВАШ_URL/exec';
```
на ваш реальный URL из шага 1.3.

---

## Шаг 3 — Разместите на GitHub Pages

### 3.1. Создайте репозиторий
1. Перейдите на [github.com/new](https://github.com/new).
2. Имя репозитория: `pmo-dashboard` (или любое другое).
3. Тип: **Public** (GitHub Pages бесплатно работает только для публичных репозиториев на бесплатном тарифе).

### 3.2. Запуште код
```bash
git init
git add .
git commit -m "feat: initial PMO Dashboard"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/pmo-dashboard.git
git push -u origin main
```

### 3.3. Включите GitHub Pages
1. Откройте репозиторий на GitHub → **Settings → Pages**.
2. **Source**: Deploy from a branch.
3. **Branch**: `main`, папка: `/ (root)`.
4. Нажмите **Save**.
5. Через 1–2 минуты панель будет доступна по адресу:
   ```
   https://ВАШ_НИК.github.io/pmo-dashboard/
   ```

## Структура файлов

```
pmo-dashboard/
├── index.html          # главная страница с 3 экранами
├── styles.css          # стили (тёмная тема, адаптив для проектора)
├── app.js              # основная логика: KPI, таблица портфеля, риски, редактирование
├── gantt.js            # Гантт-компонент по месяцам (план/факт)

├── apps-script/
│   └── Code.gs         # серверный код для Apps Script (копия для истории версий)
└── README.md           # этот файл
```

## Структура листа Google Таблицы

Лист должен называться **«Статус проектов и продуктов»** и содержать колонки (начиная с A):

| # | Колонка | Описание |
|---|---------|----------|
| A | № | Порядковый номер |
| B | Тип | «Проект» / «Продукт» (только на строках уровня 1) |
| C | Наименование | Название проекта/продукта, подгруппы или задачи |
| D | Отв. (PM) | Ответственный (заполняется только на задачах) |
| E | Приоритет | 1, 2, 3… |
| F | Динамика ДК | 🟢 / 🟡 / 🔴 |
| G | Тренд | ↑ / → / ↓ |
| H | Ключевой риск | Текст или «-» |
| I | Причина отклонения | Текст или «-» |
| J | Sep-26 План | «+» / пусто |
| K | Sep-26 Факт | «+» / пусто |
| L | Oct-26 План | «+» / пусто |
| M | Oct-26 Факт | «+» / пусто |
| N | Nov-26 План | «+» / пусто |
| O | Nov-26 Факт | «+» / пусто |
| P | Dec-26 План | «+» / пусто |
| Q | Dec-26 Факт | «+» / пусто |
| R | Jan-27 План | «+» / пусто |
| S | Jan-27 Факт | «+» / пусто |
| T | Примечание | Бизнес-эффект (заполняется на строке уровня 1) |

### Иерархия строк
- **Уровень 1** (заголовок группы): колонка B = «Проект» или «Продукт»
- **Уровень 2** (подгруппа/направление): B пуста, C заполнена, D пуста
- **Уровень 3** (задача): D (ответственный) заполнен

---

## Обновление кода Apps Script

Если вы изменили `apps-script/Code.gs`:
1. Скопируйте новый код в редактор Apps Script.
2. **Deploy → Manage deployments → Edit → Version: New version → Deploy**.
3. URL остаётся прежним — обновлять `api.js` не нужно.

## Возможности панели

| Экран | Описание |
|-------|----------|
| **📋 Портфель** | Разворачиваемое дерево задач, KPI-карточки, диаграмма статусов, фильтры |
| **📅 Гантт** | Горизонтальная шкала по месяцам, план (синий) и факт (зелёный), подсветка расхождений |
| **⚠️ Риски** | Список задач с рисками/отклонениями, сортировка по критичности |

**Инлайн-редактирование** (сохраняется в Google Таблицу):
- Клик на 🟢/🟡/🔴 → смена статуса
- Клик на ↑/→/↓ → смена тренда
- Клик на риск или причину → текстовое поле с сохранением по Enter/потере фокуса
